多端口限速管理工具 (终极版)

这是一个用于 Linux VPS 的多端口网络限速脚本。支持自动识别出站网卡，并且支持对同一个端口分别独立设置上传限制和下载限制。

🚀 一键部署与启动命令

在任何新的 VPS 上，只需以 root 权限执行以下一行命令即可完成安装并配置全局快捷键：

wget -O /usr/local/bin/speed "https://raw.githubusercontent.com/yeohdandan-rgb/vps-scripts/main/limit_port_y.sh" && chmod +x /usr/local/bin/speed


执行完毕后，在终端输入以下命令即可随时呼出管理面板：

speed


⚙️ 核心功能说明

模式 1 (单向下行/下载)： 限制用户从 VPS 下载文件的速度（限制服务器出站）。

模式 2 (单向上行/上传)： 限制用户往 VPS 上传文件的速度（限制服务器入站）。

模式 3 (双向同速限制)： 同时限制上传和下载为相同数值，并清除该端口的其他单向规则。

独立规则叠加： 你可以对同一个端口先添加“模式 1”，再添加“模式 2”，实现上下行不同速率的精细化控制。

🗑️ 如何彻底清理与卸载脚本

如果你不再需要限速功能，并希望彻底清理脚本及其产生的所有规则，请按以下步骤操作：

第一步：清空底层限速规则
在终端输入 speed 打开菜单，选择选项 6 (彻底清空所有配置)。这一步会清除底层的 tc 限速规则，并删除 /etc/port_limit_config 配置文件，恢复网卡全速状态。

第二步：删除脚本快捷命令
退出面板后，在终端执行以下命令删除全局快捷指令文件：

rm -f /usr/local/bin/speed


完成以上两步后，该限速脚本就被彻底移除了。
